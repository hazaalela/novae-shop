# NOVAÉ

A minimal, editorial-inspired fashion e-commerce website focused on timeless essentials, curated collections, and a seamless shopping experience.

## ✨ Features

- Responsive and modern UI
- Product browsing and categories
- New arrivals and best sellers
- Product detail pages
- Editorial-style landing page
- Newsletter subscription
- Mobile-friendly design

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Wouter
